# Evidencia 01 — Configuración inicial

## Configuración inicial de registro

No se guardó una captura completa de `pg_settings` antes de cambiar los parámetros de bitácora. Por tanto, los valores iniciales de `logging_collector`, `log_connections`, `log_disconnections`, `log_line_prefix` y `log_statement` no se reportan como observados. La ruta exacta de `config_file` también quedó truncada en la captura inicial.

**Interpretación:** esta limitación impide documentar de forma verificable la configuración inicial completa. No se reconstruyen valores de memoria como si hubieran sido medidos.
